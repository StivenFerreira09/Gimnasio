# Mockup del Sistema de Gestión de Gimnasio

## 1. Introducción

La Fase 5 corresponde al diseño y la documentación de los prototipos de interfaz de usuario del Sistema de Gestión de Gimnasio. Su propósito es representar visualmente las funcionalidades del sistema y definir la organización de las pantallas, los componentes visuales y la navegación para las versiones web y móvil.

## 2. Objetivo

Diseñar y documentar los prototipos de interfaz de usuario del sistema, estableciendo una estructura visual clara, consistente y acorde con los requerimientos funcionales, las historias de usuario y los roles definidos en las fases anteriores.

## 3. Alcance

Esta fase contempla:

- Definición de la estructura de navegación del sistema.
- Diseño de las pantallas principales y los formularios.
- Representación visual de las funcionalidades disponibles para cada rol.
- Definición de componentes visuales reutilizables.
- Documentación de los flujos de navegación e interacción de los usuarios.
- Registro de las diferencias entre las interfaces web de PC y móvil.
- Conservación de evidencias gráficas y enlaces a los prototipos.

## 4. Plataformas

### 4.1. Versión web para PC

La versión web está orientada al uso del sistema desde computadores. Su diseño considera la distribución del contenido en pantallas amplias, los formularios, las tablas, los paneles de información y los elementos de navegación propios de esta plataforma.

### 4.2. Versión móvil

La versión móvil está orientada al uso del sistema desde dispositivos celulares. Su diseño considera la adaptación de los contenidos a pantallas pequeñas, la navegación móvil y la disposición de los componentes para facilitar la interacción táctil.

## 5. Roles del sistema

Las interfaces contemplan los siguientes roles:

- **Administrador:** gestiona la configuración y la información administrativa del sistema según los permisos establecidos.
- **Recepcionista:** realiza las operaciones de atención y gestión de clientes que le correspondan.
- **Entrenador:** consulta y gestiona la información relacionada con sus funciones y actividades asignadas.
- **Cliente:** consulta la información y las funcionalidades disponibles para su perfil.
