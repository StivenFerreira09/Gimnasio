# 🏋️‍♂️ Sistema de Gestión para Gimnasios

Plataforma diseñada para simplificar y automatizar el control diario de un gimnasio, optimizando la administración de socios, el seguimiento de entrenamientos y el registro de ingresos.

---

## 🎯 ¿Qué queremos lograr?

El objetivo principal es eliminar los registros manuales y las hojas de cálculo desordenadas. Buscamos ofrecer un sistema centralizado que permita:

* **Facilitar la administración:** Llevar un control claro de quiénes son los socios activos y cuándo vencen sus planes.
* **Mejorar la experiencia del usuario:** Ofrecer a los entrenadores y clientes una herramienta para asignar y consultar rutinas de forma organizada.
* **Tener control financiero:** Registrar los pagos y consultar ingresos para tomar mejores decisiones.

---

## 🛠️ ¿En qué vamos a trabajar?

El proyecto abarca el desarrollo de los siguientes módulos y componentes clave:

* **Gestión de Clientes y Membresías:** Registro de nuevos usuarios, asignación de planes (mensual, trimestral, anual) y alertas de vencimiento.
* **Control de Asistencia:** Marcación rápida de ingreso para verificar si el usuario tiene su membresía al día.
* **Planes de Entrenamiento:** Creación de rutinas personalizadas con ejercicios, series y repeticiones.
* **Módulo de Pagos:** Registro de mensualidades, historial de transacciones e ingresos generados.
* **Base de Datos y Modelado:** Diseños de base de datos relacional para almacenar usuarios, pagos, asistencias y rutinas de manera segura y ordenada.
